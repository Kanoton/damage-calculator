# Build-only map and difficulty font

Noto Sans JP, weight 900, subset of Google Fonts
`ofl/notosansjp/NotoSansJP[wght].ttf` (retrieved 2026-10-18).
The adjacent OFL license applies. This font is used only when generating
local word masks; browsers neither load the font nor contact an OCR service.

Subset contains registered map names plus 普通/困難/悪夢/狂気, field labels,
and the replay suffix. Extend the subset before adding new glyphs to the CSV.
`map-text-generated.json` is a synthetic
font-rendered integration fixture, not evidence of all maps' live-game accuracy.
