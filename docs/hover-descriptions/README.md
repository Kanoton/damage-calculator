# 07 マウスオーバー説明文

## 編集するファイル

説明文の正本は [07_skill/data/hover-descriptions.csv](../../07_skill/data/hover-descriptions.csv) です。UTF-8 BOM付きで、Excel等で編集できます。重複を共通化し、従来の418行に対して167行に整理しました。能力全文35行、チップ説明90行、共通操作・個別説明42行です。

| 列 | 編集方法 |
| --- | --- |
| key | 表示先を識別する固定キー。変更しない |
| 用途 | 編集時の案内。画面には表示しない |
| 説明文 | この列を編集する。改行も表示に反映される |
| 変数 | 利用可能な差し込み名。変更しない |

`{name}`、`{state}`、`{max}` 等は名前・オン／オフ・CT上限などの差し込みです。例えば `operation.toggle` の説明文を1か所変更すると、対応する自キャラ／PTのボタンに共通して反映されます。変数は削除できますが、列にない変数を追加すると生成時に停止します。改行・カンマ・引用符を含むセルはCSVの引用符で保持してください。HTMLは使いません。

編集後のCSVを渡してもらえれば、生成・表示確認・PR反映を行います。CSVを直接書き換えただけでは配布済みの画面は更新されません。

## アプリへの反映

```sh
node scripts/build-07-hover-text.js
npm run check:07
node scripts/export-07-hover-inventory.js
node scripts/export-07-hover-inventory.js --check
```

CSVから `07_skill/js/hover-text.js` を生成します。この生成JSを通常scriptとして先に読み込み、Web版と `file://` 版の両方で同じ文面を使用します。生成JSは手編集しません。`check:07` はCSVとの一致、差し込み処理、実際のscript読み込み順の構文を確認します。

07の能力全文・チップの説明表示はこの正本を参照します。共有 `csv/character_skills.csv`、`csv/chip_list.csv` は06b／08等の既存データとして保持し、07の説明文編集では変更しません。名前・数値・アイコン・効果ルール・aria-labelは各既存データ／実装が管理します。新しいキャラやチップを追加するときは説明文のキーも追加してください。

## 対応確認用の一覧

[inventory.csv](inventory.csv) の418行は、表示先やオン／オフなどの状態別に実際の文面を確認する資料です。編集元は上記167行のCSVへ移りました。既存の「修正後の説明文」「編集メモ」は再生成時にも保持しますが、この一覧をアプリは直接読み込みません。

能力全文、固有操作、PT受領、モンスター状態、スキル・CT、入力欄、チップ、パラメータ操作を収録しています。一般のタブ操作、マップイベントのプレビュー、計算機カード操作は対象外です。モンスター固有召喚の2種類の説明も共通データへ移しましたが、418行のキャラクター能力一覧には収録していません。

抽出は既存表示関数を小さなテキストDOM上で呼ぶオフライン処理です。戦闘計算・スキル発動・CT巡回・PT総当たりを実行しません。`source-manifest.json` は参照元ハッシュと分類別件数です。参照元統一時に元の418行の文面がすべて一致することを確認しました。

表示条件・状態保持は既存仕様のままです。自キャラレンの反撃非表示、PTサイクスのエロ非表示、親友関連のPT条件、解除後の受領状態保持、CT短縮、最大値アイコンなどは今回変更していません。
