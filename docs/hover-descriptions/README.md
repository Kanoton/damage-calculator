# 07 マウスオーバー説明文の編集用一覧

[inventory.csv](inventory.csv) が第一段階の一覧です。最新mainのPR #194反映後（`7f94015`）を基に、現在の表示文面を抽出しました。Excel等で開けるUTF-8 BOM付きCSVです。

これは文面を検討するための資料です。アプリはこのCSVをまだ読み込みません。「修正後の説明文」を編集しても画面表示や計算は変わりません。

一般のタブ・画面操作、モンスター固有の召喚スキル、マップイベントのプレビュー、計算機のカード操作は今回のキャラクター能力文面の対象外です。

## 編集方法

1. 「分類」「キャラクター」「表示先」で絞り込みます。まず自キャラ・PT受領・モンスター状態から確認すると操作説明に集中できます。
2. 「現在の説明文」は抽出結果のまま残し、「修正後の説明文」に希望する文章を入力します。
3. 意図や確認事項は「編集メモ」に書きます。「確認メモ」は実装由来の補足です。
4. IDを保持してください。オン／オフ等を同じ文面にする場合も、該当する各行に同じ修正文を入れます。

空欄の修正文は未編集です。現在titleがない項目は「現在の説明文」も空欄にし、「確認メモ」に明記しました。空欄の修正文を「説明を削除する」とは扱いません。削除したい場合は編集メモへ明示してください。

「能力全文」はカスタムツールチップの本文です。それ以外の多くはtitle属性の文面で、ラベルに設定されたtitleを内部ボタン・入力欄が共有するものもあります。aria-labelは読み上げ／操作識別用の別情報なので、titleがない場合に代わりの説明として混ぜていません。

## 表示条件と動的な文面

- 自キャラの固有状態をPTの状態と混同しないでください。自キャラレンに反撃ボタンは表示しません。PTレンによる反撃は受領側に表示され、自キャラパンダマンの反撃と重複表示しません。
- 受領状態が残れば供与PTを外した後も操作が表示される場合があります。PTパンダマン回復操作は供与PTが必要です。テルの憑依／狐光表示は保持状態でも残りますが、追撃計算には登録されたPTテルが必要です。
- 親友を守るは自キャラハンナかつPTシェリーのみ。親友の祝福の専用操作は自キャラシェリーかつPTハンナ／保持された受領移動状態で表示します。
- PTサイクスではエロ操作を表示しません。フェイト・エコーはPTカイセイがいる場合と、残数がある場合で文面を分けています。
- CT上限はチップ15によって1減少します。覚醒／人形制作の初期表示と値編集後は操作文の記号も異なるため別行です。愛の上限拡張やパッドマンのスキル中の入力無効化はtitle自体を変更しません。

表示条件は関連実装から整理した条件です。全PT組合せやゲーム内能力の総当たり検証結果ではありません。

## 再生成・確認

```sh
node scripts/export-07-hover-inventory.js
node scripts/export-07-hover-inventory.js --check
```

スクリプトは既存の表示関数を小さなテキストDOM上で呼び出し、CSV正本・ルール・表示条件の関連部分を読みます。アプリ全体やブラウザを起動せず、戦闘計算・スキル発動・CT巡回・PT総当たりを実行しません。新しい実装で抽出箇所が変われば、スクリプトとこの収録範囲を見直してください。

再生成は同じIDの「修正後の説明文」「編集メモ」を保持します。編集済みのIDが消える場合はエラーで停止し、手動レビューを求めます。その他の列は再抽出します。`--check`は現在の抽出結果とCSV・source-manifest.jsonの一致を確認します。

[source-manifest.json](source-manifest.json) には参照元のハッシュと分類別件数を保存しています。文面の調整が終わった次の段階で、承認された文面の参照元統一とHTTP／file://の表示確認を行います。現段階では07、共有CSV、08の実装を変更していません。
