# ミニキャラ画像対応表

2026-10-08に `main` の `b573122d0b3d7913afeea4fe6fe46c12a3c07726` を基準として、`images/UT_Hero_ProfilePhoto/` の194枚を全件目視照合しました。既存の `mini_character_mapping.csv` はmainとその履歴に存在しなかったため、`csv/mini_character_mapping.csv` として新規作成しています。前Workの未保存CSVとの差分は比較できません。

キャラクターは `csv/character_stats.csv`、`08_screen_reader/csv/character_hero_card_mapping.csv`、`images/character/`、`images/UT_Hero_Card2/`、モンスターは `csv/monster_stats.csv` と `images/Monster/` を照合元としました。ファイル番号だけからキャラIDを推測していません。

| 列 | 内容 |
| --- | --- |
| image_file | UT_Hero_ProfilePhoto内のファイル名。主キー |
| entity_type | キャラクター／モンスター／判別不能 |
| character_id | character_statsのID。キャラクター以外は空欄 |
| monster_ids | monster_statsの候補ID。複数の場合は `|` 区切り |
| name | 正本の名前。複数の名称は ` / ` 区切り。判別不能は空欄 |
| reader_target | 対象／対象外。モンスターと判別不能は対象外 |
| status | 確認済み／候補複数／判別不能 |
| reference_images | 照合元のリポジトリ相対パス。複数は `|` 区切り |
| notes | 衣装違い、複数候補、判別できない理由 |

UTF-8 BOM付き・CRLFのCSVです。194行の内訳はキャラクター130枚（35人）、モンスター59枚、判別不能5枚。ファイル名の重複・一覧の欠落は0件、同一バイトの画像ファイルも0組です。同じキャラクターの別衣装は同じID・名前にまとめています。

モンスターの10画像は、正本で同じ姿が複数IDに使用されているため「候補複数」です。味方・敵、難易度や登場場面によるID差を画像だけで確定していません。`1054` は三つの爆竹が描かれているため「三連爆竹ゲロゲロ」としました。`1016` は正本で単体・三連に同じ単体画像が割り当てられているため、両候補を残しています。

## 読み取り側との関係

08の見本登録欄がCSVを読み、選択したキャラの全衣装画像を確認用に表示します。CSV取得不能・不正時と `file://` 起動時は生成済みの同梱対応表を使います。対象外画像をキャラ登録に使用しません。画像の名前の対応づけと、実ゲーム画面の自動認識精度は別の検証です。既存の認識特徴、閾値、チップ蓄積、自キャラ判定は変更していません。

更新手順：CSV編集 → `python3 scripts/build-mini-character-mapping.py` → 同コマンドの `--check` → `npm run check:08` → `npm run test:08`。同梱JSは直接編集しません。
