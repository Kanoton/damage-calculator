## 今の画像処理へ通した結果

- ルーム設定、結果画面、ロード中のカード4枚からマップ／難易度／PTを取得する処理はまだない。これらの画面をそのまま渡しても4枠は未判定、worldも未判定。今回、自動設定を実装済みとは扱わない。
- 開始後のHUDでは実プレイ37秒／47秒に4人のID、リプレイ9秒／15秒にも4人のIDを判定できた。新しい2本の左下見本を追加した後は、自キャラ13／2も判定できた。今回保存するのは左下の顔領域だけ。
- ただし数値は全項目が正しいわけではない。リプレイ9秒ではパルナンのHPを0、15秒ではシェリーのHPを1と出すサンプルがあった。今回の本人判定・チップ画面保護でHP読取全体が解消したとは記録しない。HUDの拡縮・選択レイアウト・数字の領域を後続で切り分ける。未知の数字を既知の基礎HPへ補完しない。
- リプレイ15秒の画面から海賊サメ3番10/10を取得。他の個体を全件取得できたことは確認していない。実プレイの秋幻の森は現在の名前照合25種に新規5種が入っておらず、出現・HPが映っていても当該個体は未判定になる。CSV登録とゲーム画面の名前見本対応は別の作業。
- 両動画の抽出サンプルではチップ追加候補は0。これだけで元の誤追加場面を再現したとは扱わず、一覧の丸枠がない合成負例と既存の正例も回帰確認する。

## 撃破の確認

- 実プレイ約68秒以降で目覚ましフクロウとの戦闘へ移行。マップ上のHP文字から、キャラ直下のハート＋HPへ表示形式が変わる。
- 約81.5～83秒でダメージ演出と個体の消失、約82.7秒で「目覚ましフクロウが倒されました！」の通知を確認。約84秒以降はマップへ戻る。
- 約82.7秒の実フレームを現在のworld画像処理へ渡してもmonstersは空。戦闘HP、撃破通知、戦闘対象をマップの個体番号へ引き継ぐ処理はいずれも未実装で、この場面の自動撃破はできない。名称だけの通知では同種のどの番号か確定しない。
- 今後は戦闘前の対象（名前＋番号）→戦闘開始→明示的な撃破通知を照合し、対象を特定できない／観測を飛ばした場合は保留する。マップ上で消えただけでは撃破にしない方針を維持する。

## 次の実装の順序

1. ルームのマップ・難易度を別々に判定し、思考時間を難易度として読まない。リプレイは結果画面下側のマップ／難易度を候補として保持し、実際のリプレイ開始と結び付ける。以前の結果だけで現在の試合を切り替えない。利用者の手動指定を優先する。
2. ロード画面で4枚の選択キャラを読み、全員確定する前の変更や、プレイヤーのアカウントアイコン／バナーからキャラを推測しない。YOUがある実プレイと、YOUのないリプレイを分け、HUDの順番と照合後に固定する。
3. 新動画のHUD数値の誤読と、秋幻の森の名前見本不足を解消する。
4. 戦闘対象の個体番号を引き継いで、撃破通知を明示的な根拠として適用する。
