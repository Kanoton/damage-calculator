# マップ情報・まとめ画像の制作手順

2026年10月15日確定。対象：アストラルパーティー「秋幻の森」。

## 次回の進め方

1. マップ名・難易度と、添付された画像・動画・既存データを確認する。
2. ミニマップからマスの種類・名前・接続を整理し、動画の「進捗」表示からイベントとマップミッションを読む。ラウンド数を進捗の代わりにしない。
3. まずモンスターなしの基本マップを作る。接続やマスを推測で追加せず、不明な点を具体的に示す。
4. 各イベントについて、出現マスを緑枠で囲った画像と、同じ位置にモンスター名を添えた確認用画像を作る。モンスター画像は貼らない。
5. 利用者が名前入り画像で配置を確認し、緑枠のみの画像へモンスター画像を貼る。利用者が返した調整図を以後の正本として使用し、独自に配置を戻さない。
6. 承認済みの図・テキスト・能力値からまとめ画像を作成する。まず1難易度で確認し、合意後に全難易度・全形式へ展開する。
7. 全画像の文字切れ、重なり、難易度、能力値、ゲームオーバー進捗、画像サイズを確認し、ZIPで納品する。

## イベント図の新しい分担

- 作成側：出現箇所の読み取り、緑枠のみの図、モンスター名を入れた確認用図、位置対応表。
- 利用者：モンスター画像の貼り付けと最終的な配置調整。
- 名前入り図と緑枠のみの図は同じ座標・サイズで作る。名前はマップの接続線・他の名前・隣のマスに重ならない位置に置く。外周沿いの名前は原則として内側へ配置する。
- 同じマスに複数のモンスターが出る場合は、人数・種類が分かるように名前を分けて表示する。
- このZIPの `Frames` は貼り付け作業用、`Names` は確認用。モンスター画像はどちらにも含めない。

## マップ図の確定ルール

- ゲーム内ミニマップは45度傾いているため、図では45度回転して見やすくする。回転方向は対称性を優先し、極端に横長になる場合は縦長になる方向を選ぶ。
- マスのイラストも図の向きに合わせる。接続線は水平・垂直・45度の直線で整え、スクショ由来の微小な座標ずれを残さない。
- 秋幻の森は上下対称。上下の横一列は角のマスまで含めて5マスを均等配置する。今回の図ではその横方向の中心間隔は180px。斜め区間を含む全区間の距離が同一という意味ではない。
- 以前「？」とした追加マスは存在せず、3rd・4th側に接続するマスそのものが角になる。存在しないマスを復活させない。
- ショップに相当する「？」はショップマスとして扱い、名前対応の素材がない場合は緑のショッピングカートのマスを使う。「？」を未確認マスとして描かない。
- 建物設置マスは青い枠で囲み、基本マップの下に「建物設置マス」と注記する。イベント図の出現位置は緑枠にし、枠の意味を混ぜない。
- 今回の原寸図：1804×1948px。マスの素材サイズ72px、接続線12px。基本マップと座標データを同梱している。

## まとめ画像の確定仕様

### 縦長

- 各難易度2枚。両方2240×3329pxに統一する。
- 1枚目：マップ名・難易度、マップミッション、進捗イベント、基本マップ、イベントカードと出現位置図。
- 2枚目：マップ名・難易度、マップ固有カード4枚と設置効果の説明、モンスター情報。

### 横長

- 各難易度1枚、WQHDの2560×1440px、16:9。
- 左列：ミッション、進捗イベント、基本マップ。
- 中央列：イベントカードと出現位置図4組、マップ固有カード4枚と説明。
- 右列：モンスター情報。

### 共通の表記・装飾

- 種族は表示しない。キッズガオーの名前の後ろにボスマークを付ける。
- モンスターは左列にキッズガオー→目覚ましフクロウ、右列におもちゃの恐竜→採集クマちゃん→泥棒。
- 「みなぎる元気」「ガオーの注目」の説明は、キッズガオーのパッシブ2つの下に置く。「マップ固有ギミック」という見出しは使わない。
- パッシブ本文に出てくるキーワードの直前に、本文文字と同じサイズのアイコンを置く。キーワード全体を太字にし、途中で改行しない。
- みなぎる元気は紫 `#7546A6`、ガオーの注目は青 `#246B9B`。効果説明の見出しにも同じ色を使う。オレンジは既存のスキル・パッシブ見出しなどと区別するためキーワードには使わない。
- アイコンは元画像を使い、説明は画像の文章部分を貼るのではなく文字として入力する。
- 「モンスター情報」見出し右の能力値注釈と、画像最下部の確認事項は載せない。

## マップ固有カードと設置効果

今回はマップ固有チップなし。カードは疾走キノコ、仙果スターフルーツ、芳香ピーチ、金運の木の4枚。

|名前|カードの下に載せる設置後の効果|
|---|---|
|疾走キノコ|止まった時、次の移動力+3|
|仙果スターフルーツ|止まった時、HP上限+1|
|芳香ピーチ|通過時、キャラクターのHPを2回復し、【ガオーの注目】を解除する|
|金運の木|ラウンド開始時、5マス以内の全キャラクターがスターコインを3獲得する|

カード画像の下に、アイコンだけを切り抜いたものと入力した効果説明を配置する。カード自体の画像に書かれた使用効果も残す。

## 能力値・データ更新時の注意

- 難易度別ステータスは渡されたデータを使う。キッズガオーはM0120、採集クマちゃんはM0121、おもちゃの恐竜はM0122、目覚ましフクロウはM0123、泥棒はM0005。
- キッズガオーのHP60%条件は普通72・困難78・悪夢84・狂気90。
- 目覚ましフクロウのHP50%条件は整数HP基準で普通4・困難4・悪夢5・狂気5。
- 能力値だけでなく説明中のHP条件の実数も難易度に合わせる。進捗7・10による強化は基礎能力値へ先に足さない。
- 画像だけでは判断できないスキルやゲームルールを補完しない。
- 今回の提供素材には潜在解放ルカ、変更されたチップの情報も含まれていた。図の制作手順とは別の正本データとして扱い、新規資料の変更点と反映状況を確認する。
- リポジトリを変更する場合は `https://github.com/Kanoton/damage-calculator` の最新main、AGENTS.md、WORKING_GUIDE.md、引き継ぎ書、直近PRを確認する。チャット内の古いデータを最新mainより優先しない。ただし今回の利用者調整図・出現位置の変更を過去案へ戻さない。
- 承認済みのまとめ画像は `production/summaries/`、最新出現位置は `production/event_spawn_locations.csv`、座標データは `production/data/topology.json` に保存している。旧生成スクリプトのハードコードされた出現位置よりこちらを優先する。

## 次回、そのまま使える依頼文

> 添付の制作手順書に従って、マップ情報とまとめ画像を作成してください。最初にマップ名・難易度、素材と既存データを確認し、接続・ミッション・進捗イベント・モンスター名を整理してください。イベント図は「出現マスを緑枠で囲った画像」と「確認用のモンスター名入り画像」の2種類を作り、モンスター画像は貼らないでください。画像の貼り付けと配置は私が行います。返却した調整済み図を使って、まず1難易度のまとめ画像を確認し、その後に全難易度を縦長2枚・横長WQHD1枚ずつ作成してZIPでください。パッシブ本文の効果名には文字サイズのアイコンを添え、みなぎる元気は紫、ガオーの注目は青の太字にし、説明見出しの色も統一してください。不足情報は具体的に知らせてください。
