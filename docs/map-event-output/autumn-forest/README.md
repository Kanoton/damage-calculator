ユーザー提供の通常プレイ動画2本、ミニマップ、マス素材、`261015.zip` の32画像を根拠とする。

- `csv/monster_stats.csv` に4種類×4難易度を追加。`csv/monster_skills.csv` は難易度別スキル文と元画像名を保存する新しいデータファイル。現行アプリでは説明画像を表示し、このスキルCSVを自動実行する仕組みはない。
- `MonsterInfo/M012x_info_1..4.png` は普通・困難・悪夢・狂気の順。ボスは2スクロール位置を縦に結合。全文のうちゲーム画面で見える範囲を保存している。アイコンは右下のモンスター選択欄から切り出した暫定素材。
- O18a/O29aは実在しないので削除。隣接するO18/O30を角へ移動した56マス図。時計回り45度で1798×1942pxとなり、反時計回りの場合の横長を避ける。描画座標は上下の線対称へ整形し、内側の曲がりも直角に統一。マス順序・接続は保持。マス素材は回転後の主な辺と角度を合わせて正立配置。I18–O24の接続と初期進行方向は引き続き暫定。
- `topology.json` は位置・接続・通常の出現位置を保存する。`python3 scripts/render-autumn-map.py` で本図・確認用番号図・イベント図4枚を再生成できる。必要なPillowとDejaVuフォントは従来の生成環境と同じ。
- 今回の明示指定により、従来の「緑枠のみ」から、このマップに限りモンスターアイコンを暫定配置。アイコンはマス72pxの約1.2倍（長辺86px）とし、角に18px重なる位置へ配置。外周のものは内側の角を選び、12pxの接続線に2px以上の余白を確保する。進捗7のO16のクマと恐竜は内側の別々の角へ置き、同じ緑枠で示す。全14体は接続線・他のアイコン・別のマスを避けている。配置座標とサイズは `event-icon-layout.json` に保存。
- 通常の進捗3/7/10は2動画の生成場面を比較して配置が一致した。進捗1の図は観測配置であり、2動画での全配置一致を独立確認したものではない。固定/ランダムの追加検証は引き続き必要。CSVの出現位置画像の有無を固定判定として利用しない。
- イベント・ミッション・終了進捗18は通常のみ確認。困難・悪夢・狂気へ通常の進捗や出現数を流用しない。マップ選択で他難易度のモンスターの基礎ステータスは表示できる。
