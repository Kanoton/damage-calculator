# 画面読取：撃破判定の素材と開発状況

2026-10-19、利用者提供の `秋幻.zip` を受領し、秋幻の森の動画10本を確認した。撃破9本（クマ3／フクロウ2／恐竜2／泥棒2）と出現イベント1本。ボス撃破はクリアになるため未撮影という利用者の説明に従い、今回の対象に含めない。

## 保存済みの素材

[検証用データと一覧](../tests/fixtures/screen-reader/defeat/autumn-reviewed-20261019/README.md) に、短い動画10本・可逆圧縮の41フレーム・正解ラベル・元動画のハッシュ／フレーム番号／実時刻・既存読取の結果を保存した。原ZIPや全画面動画そのものはコミットせず、撃破を確認するためのマップ上の前後区間を切り出している。

- 原動画は全て2560×1440、約29〜30fpsの可変フレーム間隔。ゲーム内の再生倍率と難易度設定の印字は未確認なので、前回の「困難」や10倍速を流用しない。全て提出動画の時刻で記録する。
- 左のプレイヤー名欄、上部の通知、下部の手札UIを避けた `[640,360,1600,760]` の範囲を、拡大縮小せず保存。音声と入力のメタデータは除外。キャラとの重なり、残った別キャラ、他の生存モンスター、カメラ移動は残す。
- 動画はH.264 CRF18の確認用再圧縮。フレームは元動画から直接採ったWebP可逆圧縮で、元RGBのSHA256も保持する。動画のフレーム数・時刻対応を確認し、全ての静止画をデコードして元画素との一致を検証した。
- 個体番号は映像で確認したものだけ記録。動画名の「2」を個体番号に読み替えない。例えばフクロウ撃破2は **3番**、恐竜撃破は **2番**。キッズガオーの姿や生存HPが映る例もあるが、ボス撃破の正例ではない。

## 演出を確認した結果

マップでは、色付きの生存姿から暗いグレーの姿へ変化し、固有の姿勢変化を経て、青白い光柱とともに消滅する。クマは傾いたり縮む動き、恐竜は立ち姿から横倒し、泥棒は体・袋を傾ける動きが見られる。フクロウは手前の1〜2人に体を隠されるが、頭・右側の輪郭や動きが残る。全身の一致を前提とする見本にはしない。

戦闘画面のダメージ／撃破表示と、マップへ戻ってからのグレー化・消滅は別の場面として確認した。クマ撃破2・泥棒撃破2では、マップ上のカード攻撃後に同様の消滅へ進む。マップ上の対象の変化が共通の検証対象になる。

**出現時にも似た青白い光柱がある。** イベント1を非撃破の比較素材にし、光だけ、HPラベルが消えたことだけ、カメラ移動で対象が範囲外になったことだけでは撃破にしない。攻撃の光も消滅の光と区別する。消える前の暗い姿・姿勢の変化と、消えた後も他のキャラが残ることなどの時間関係を使う必要がある。

## 全身が見えることを必須にしない方針

利用者はキャラとの重なりがある映像も認識することを明示した。データの `full_body_required` はfalse。次の候補判定でも、全身・全輪郭の一致や、対象の全ての画素がグレーになることを採用条件にしない。

名前・番号で事前に確認した個体に対し、見える複数の部分（頭・袋・尻尾など）の暗色化・姿勢変化を追う。隠れた部分は不一致と数えず、見えている証拠を組み合わせる。名前が隠れた瞬間に別の近い個体へ付け替えない。光が隠れる場合も、確認できる部分を候補の根拠にし、全てが見えないフレームでは保留する。ボスなど別の生存個体のHPを、消えた敵の撃破へ誤って結び付けない。

## 既存読取へ通した結果と未実装の範囲

`text-reader-baseline.json` は、保存した41画面を元位置の黒塗りキャンバスへ戻し、現在の `ScreenReaderWorldVision` にNative Canvasで通した結果。使用JSのSHA256を保存している。クマ2番、フクロウ1／3番、恐竜2／1番、泥棒2番の撃破前ラベル等を読めたが、グレー姿・消滅そのものを撃破として返す処理は現在ない。マスクしたHUD・時計が読めないことは、この検証の失敗とはしない。これはブラウザ精度や撃破の自動検出率の評価ではない。

**今回は素材の登録・目視確認・既存読取の基準結果まで。** `08_screen_reader` の認識コード、候補表示、追跡、自動確定は変更していない。自動撃破OFFを保持し、HP0／不在だけを理由に解除しない。次の実装では、この部分遮蔽の9例と出現の非撃破例を使い、候補と正解を比較する。未提供のボス撃破の精度は評価しない。

## 再生成・検証

```sh
python3 scripts/build-autumn-defeat-samples.py --source /path/to/秋幻.zip
python3 scripts/build-autumn-defeat-samples.py --check
# 任意の既存読取の再計測（開発用依存、アプリへは追加しない）
npm install --no-save --package-lock=false @napi-rs/canvas
node scripts/inspect-defeat-samples.cjs
```

再生成はFFmpeg／FFprobeとPillowが必要。通常の確認は保存済みファイルのハッシュ、41画面のデコード・RGBハッシュ、フレームと時刻、正解情報との対応を検証する。08のCIにも保存素材の確認を追加している。入力ZIPがなくても、保存した動画・フレーム・正解ラベルから検証を再開できる。
