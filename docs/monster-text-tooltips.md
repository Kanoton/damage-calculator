# 08 モンスター説明の文字データ

正本は `csv/monster_stats.csv` の `能力` 列（複数行CSV）。`monster_id` と `難易度` が一致する行を、モンスター一覧／出現中カードの両方で参照する。07・保存版の画像ホバーは今回変更していない。

既存の `info` 列が指す `images/MonsterInfo/` の76枚を文字に移し、221行へ反映した。CT、範囲、対象、増減符号、持続時間、難易度別の閾値を含む。改行・句読点・表記を読みやすく整え、画像上部の名前・種族はCSVの既存列から表示する。説明の表示だけを変更し、能力計算・動画読取・撃破判定のルールは変更しない。

- `info` と元画像は出典および旧版互換のため保持する。08の説明本文は画像を読み込まない。
- 画像がない74行（難易度なしの18行、M0101〜M0114の56行）は能力を空欄とし、表示時は「説明は未登録です。」とする。他の難易度や別形態から補完しない。
- M0003の憤怒、M0006のCT、M0009/M0010のHP減少値、M0013/M0030/M0031/M0042/M0044/M0045/M0049/M0051の追加能力、M0120/M0123のHP条件など、画像の違いを行ごとに保持する。
- M0023「紙装甲」の「最大0まで」は元画像の表記どおり。計算ルールの解釈・訂正はこの転記では行わない。
- 既存の `csv/monster_skills.csv` は別の調査資料で、今回のホバーの参照元ではない。

更新後は `python3 scripts/build-08-monster-text.py` で08同梱snapshotを再生成する。`npm run check:08` は画像参照・文字起こしの欠落／同じ画像に対する文章不一致・snapshot同期・通常scriptの構文と連結順を検証する。HTTPのCSV取得と、取得失敗時／file://の同梱データで同じ文章を表示する。

キャラ一覧と共通の配色、430px幅、14px本文、能力見出し、2列ステータスを使う。モンスターは選択中の難易度の基本値（攻撃／防御／HP／コイン）を表示する。出現中カードの手動補正・スタック等による現在値はカード本体を参照する。長文はスクロールでき、フォーカス／Escape、画面端での位置調整に対応する。
