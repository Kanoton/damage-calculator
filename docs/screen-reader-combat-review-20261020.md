## 利用者からの説明

- 通常の戦闘開始はマップ上のアイコン接触。突撃ゲート等は対象選択から戦闘へ入る。他プレイヤーの突撃ゲートでは選んだ一覧が見えなくても、移動先のモンスターから候補を得られる。
- ナンシーローのスキルでは、名前・個体番号・現在／最大HP・攻防などが並ぶ一覧で対象を選ぶ。緑枠が選択中の対象。
- 戦闘開始時には攻撃を受ける側のカットが入る。添付 `UT_Monster_Bust_1074_0.png` はフクロウの例で、実際には背景付き。カット画像は種類の手掛かりであり、個体番号を保証しない。
- 攻撃側は左・赤、防御側は右・青。反撃により攻防が入れ替わるので、開始時の役割を固定しない。
- カード／スキルによる戦闘外の撃破は戦闘画面へ遷移しない。直前の名前と個体番号、部分的な撃破モーション、消失を追う。全身の表示・一致は必須にしない。
- 反撃の参照動画は利用者が準備予定。現時点では未受領。

## 次回実装に向けた案

以下は利用者の希望を踏まえた設計案。実装着手は別途依頼時とする。

1. 対象個体が未確定でも、戦闘ごとに参加者候補、左右の役割、観測時刻、開始時／現在HP、画面から読めた能力を保存する。未確定データを任意の既存個体へ書き込まない。
2. 一覧の緑枠・名前・番号を記憶し、選択変更・キャンセルを考慮する。戦闘開始を確認して、その直前の最終選択と結び付ける。
3. 一覧を取得できない場合は移動先・種類・直前のHPで候補を絞る。候補範囲を十分に把握でき、対応する個体が1体だけなら確定する。同種複数でも開始時HP一致が1体なら絞れるが、古いHPや読み落としによる見掛け上の1体で確定しない。
4. 個体が確定したら、その個体のマーク・スタック等を参照して計算へ引き継ぐ。基本能力、カード等の補正、ダイス確定値を区別し、戦闘画面の補正済み表示へ状態効果を二重加算しない。
5. 開始カットは相手の種類・能力取得の補助。現在の攻防は左右とATTACK／DEFENSEの表示で照合する。攻撃アニメーション中に相手側へ移動した瞬間の位置だけでは役割を変更しない。反撃でも同じ参加者・個体情報を保持して役割を更新する。
6. 自キャラの参加を確認してから、自キャラが攻撃側なら攻撃タブ、防御側なら防御タブへ切り替える。他プレイヤーの戦闘を自キャラの戦闘として扱わない。
7. 戦闘外は直前の名前・番号・位置と、見える部分のグレー化／固有モーション、消失後の観測を時間順に結び付ける。カメラ移動、遮蔽、ラベル不在だけでは撃破にしない。同じ場所に重なる複数体のイベントを1件へまとめず、残った個体を確認する。
8. 判別不能は候補のまま保持し、根拠が増えた時点で再照合する。リセット・新ゲーム・共有対象変更時の追跡持ち越しを防ぐ。番号再利用の仕様は未確認。

## 今後ほしい素材・情報

全部を先に用意する必要はない。既存素材で進め、失敗場面を追加できる。各クリップは可能なら操作前の対象表示から、演出後に表示が落ち着くまで含める。分かる範囲で正しい対象名・番号・結果、マップ名・難易度・倍率を添える。

| 優先度 | 素材・情報 | 確認目的・状況 |
|---|---|---|
| 最優先 | 反撃で攻撃／防御が入れ替わる一連の動画 | 利用者が準備予定。入れ替わり前後の左右・表示色・能力・HP、参加者の保持とタブ切替を確認 |
| 高 | モンスター側から自キャラへ戦闘が始まる動画 | 自キャラが最初から防御側になる場合の参加者識別と開始カットを確認 |
| 高 | 名前が遮蔽／画面外で消え、再び表示される動画 | 一時非表示を撃破にしない。出現の光柱も非撃破の比較例にする（秋幻の既存出現見本は保存済み） |
| 高 | 同種・同じ現在HPの複数個体がいる戦闘 | HPだけで確定できない場合の候補保持・後続情報による照合 |
| 中 | マーク・スタック付き個体の一覧選択から戦闘まで | 個体と状態の引き継ぎ、補正済み能力との二重加算防止。今回一覧にも状態アイコンは見えるが、全効果の計算一致は未検証 |
| 中 | 一覧で選択先変更、またはキャンセルする動画 | 最終選択を採用し、緑枠の一時選択やキャンセルを戦闘確定にしない |
| 情報確認 | 撃破後に同名・同番号が再利用されるか | 再利用されるなら、出現時期も個体識別へ含める。現時点で仕様を推測しない |

現在ある「クマ11→4で生存」の例は既に非撃破の比較に使える。通常の生存例を改めて必須素材として要求しない。新しい種類の素材が必要になっても、全モンスター分の全身素材を先に必須としない。
