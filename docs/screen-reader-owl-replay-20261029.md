# 2026-10-29 フクロウ撃破の再現と形状見本補強

基準main `7f423609`。利用者の診断JSONでは初期フクロウ1〜3番のHPと戦闘対象が保持できる一方、gray_detected／identity_confirmed／appliedは0件だった。今回、同じリプレイを10倍速にした18.966667秒・2560×1440・30fpsの動画を提供された。秋幻の森は映像から確認。難易度「狂気」は対応する診断JSONの設定と最大HP10との整合に基づき、動画内設定画面を独立に読んだものではない。

## 原因と再現

Native Canvasで全569フレームを元の通常速度相当の時刻（動画秒×10）に置いて現行trackerへ通すと、種類候補・撃破候補とも0件。撃破前のHP・番号の取りこぼしを原因として仮定しない。画面内に実際に暗い姿が残るが、既存の部分形状見本との照合で棄却されていた。

- 4.767／4.800秒はフクロウが最良候補でも誤差約0.158889／0.149064で上限0.14を超える。
- 12.633〜12.700秒は別姿勢と重なりで約0.226〜0.244、18.200〜18.267秒は約0.194〜0.227。早い姿勢では別種が最良になる場合もある。
- 従って取得間隔を短くするだけでは、この保存動画の不一致は解消しない。10倍速化前の全フレームはこの動画にはないため、実機の個々の取得時刻・取り逃しを再現したとは扱わない。
